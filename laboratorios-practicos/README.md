Desinfecte los datos (enmascarando nombres y datos personales) antes de pedirle a una modelo que emita juicios sobre datos.
Realizar auditorías periódicas de sesgos con diversos casos de prueba en todos los grupos demográficos.
Utilice métricas de equidad (igualdad de oportunidades, paridad estadística) para cuantificar el sesgo.
